# Customer_Behavior_Analysis.
This is for practise purposes. It involves Python for data cleaning and SQL for analysis. PowerBi is used for visualization.

Project Overview

This project explores customer shopping behavior using data analysis and visualization techniques. The goal is to uncover insights into purchasing patterns, customer segmentation, and discount trends to support better business decisions.

Objectives

* Analyze customer purchase patterns
* Identify top-performing product categories
* Understand discount usage across items
* Segment customers based on purchase behavior
* Support business insights with data visualization

Tools & Technologies

* Python (Pandas)
* SQL (PostgreSQL)
* Power BI (Data Visualization)
* Jupyter Notebook
